# SRS — Software Requirements Specification

## 1. Название проекта

Платформа бизнес-аналитики и визуализации данных.

## 2. Цель проекта

Цель проекта — создать простую систему, которая помогает пользователю загружать данные, просматривать их и получать визуальный результат в виде графиков и отчётов.

Проект выполнен как учебный курсовой проект. Основной акцент сделан на планировании, документации, GitHub, Jira и описании архитектуры.

## 3. Пользователи системы

- Аналитик
- Менеджер
- Администратор

## 4. Описание системы

Система должна позволять пользователю работать с данными. Пользователь загружает файл с данными, после чего система показывает информацию в таблице и строит графики.

## 5. Функциональные требования

### FR-1. Загрузка данных

Пользователь должен иметь возможность загрузить CSV-файл с данными.

### FR-2. Просмотр данных

Пользователь должен иметь возможность просмотреть загруженные данные в виде таблицы.

### FR-3. Фильтрация данных

Пользователь должен иметь возможность фильтровать данные по нужным параметрам.

### FR-4. Визуализация данных

Система должна отображать данные в виде графиков и диаграмм.

### FR-5. Формирование отчётов

Пользователь должен иметь возможность сформировать простой отчёт по результатам анализа.

### FR-6. Управление проектом

Проект должен быть размещён на GitHub и запланирован в Jira.

## 6. Нефункциональные требования

### NFR-1. Простота использования

Интерфейс должен быть понятным для пользователя.

### NFR-2. Надёжность

Система должна корректно обрабатывать данные и не завершать работу при ошибке загрузки файла.

### NFR-3. Читаемость проекта

Структура проекта и документация должны быть понятны преподавателю и другим студентам.

### NFR-4. Расширяемость

Проект должен иметь возможность дальнейшего развития: добавление новых графиков, отчётов и источников данных.

## 7. Ограничения проекта

Проект является учебным. Основная часть работы выполнена через GitHub и Jira в браузере. Реализация функций описана как план разработки и демонстрация структуры проекта.

## 8. Итог

Данный проект показывает основные этапы разработки программного продукта: описание требований, планирование задач, работа с GitHub, создание архитектуры, тестирование и подготовка к защите.
