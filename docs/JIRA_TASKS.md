# JIRA_TASKS — Задачи для Jira

## Описание

В этом документе описаны задачи проекта для Jira. Проект разделён на два спринта. Каждый спринт длится 2 недели.

## Sprint 1 — Планирование и документация

### BAD-1 — Создать GitHub репозиторий

**Story Points:** 3

Создать репозиторий на GitHub и подготовить базовую структуру проекта.

### BAD-2 — Добавить README

**Story Points:** 3

Создать файл README.md с описанием проекта, его цели и основных функций.

### BAD-3 — Создать SRS

**Story Points:** 5

Подготовить документ с функциональными и нефункциональными требованиями проекта.

### BAD-4 — Создать Product Backlog

**Story Points:** 5

Сформировать список задач проекта для дальнейшей работы в Jira.

### BAD-5 — Настроить Jira

**Story Points:** 3

Создать Scrum-проект в Jira и настроить рабочую доску.

### BAD-6 — Запланировать Sprint 1

**Story Points:** 3

Распределить первые задачи проекта по первому спринту.

### BAD-7 — Создать диаграмму прецедентов

**Story Points:** 5

Подготовить диаграмму, которая показывает основные действия пользователя в системе.

### BAD-8 — Создать диаграмму компонентов

**Story Points:** 5

Показать основные части системы и связи между ними.

### BAD-9 — Создать диаграмму последовательности

**Story Points:** 5

Показать порядок действий при загрузке и отображении данных.

### BAD-10 — Подготовить структуру документации

**Story Points:** 7

Создать папку docs и добавить основные документы проекта.

**Итого Sprint 1:** 44 Story Points
