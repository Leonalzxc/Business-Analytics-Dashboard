# Платформа бизнес-аналитики и визуализации данных

## Описание проекта

Платформа бизнес-аналитики и визуализации данных предназначена для загрузки, обработки и отображения информации в удобном для пользователя виде.

Система позволяет загружать данные из CSV-файлов, просматривать их в виде таблиц, строить графики и формировать отчёты.

## Цель проекта

Создать удобный инструмент для анализа данных и визуализации основных показателей деятельности организации.

## Основные функции

* Загрузка CSV-файлов
* Просмотр данных в таблице
* Фильтрация данных
* Построение графиков
* Формирование отчётов

## Используемые технологии

* GitHub
* Jira
* React
* CSV

## Структура проекта

* Документация
* Планирование проекта
* Визуализация данных
* Отчёты
