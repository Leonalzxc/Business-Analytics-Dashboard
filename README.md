# Business Analytics Dashboard

## Описание

Business Analytics Dashboard — это проект для анализа и визуализации данных.

Пользователь может загружать данные из CSV-файлов и получать информацию в виде таблиц и графиков.

## Основные функции

* Загрузка CSV-файлов
* Просмотр данных
* Построение графиков
* Создание отчётов

## Используемые инструменты

* GitHub
* Jira
* React
* CSV
