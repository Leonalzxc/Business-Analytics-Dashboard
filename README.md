# Business Analytics Dashboard

## Описание проекта

Business Analytics Dashboard — это веб-платформа для бизнес-аналитики и визуализации данных.  
Система позволяет загружать данные из CSV-файлов или базы данных, обрабатывать их, строить интерактивные графики и формировать отчёты.

## Цель проекта

Цель проекта — разработать удобный инструмент для анализа бизнес-данных, который помогает пользователям быстро получать информацию о продажах, клиентах, доходах и других показателях компании.

## Основные функции

- Регистрация и авторизация пользователей
- Загрузка CSV-файлов
- Подключение к базе данных PostgreSQL
- Просмотр данных в виде таблицы
- Фильтрация и сортировка данных
- Построение графиков и диаграмм
- Генерация отчётов
- Отправка отчётов по e-mail

## Используемые технологии

- React — frontend
- Recharts — визуализация графиков
- FastAPI — backend
- Python Pandas — обработка данных
- PostgreSQL — база данных
- Docker — контейнеризация
- GitHub — контроль версий
- GitHub Actions — CI/CD
